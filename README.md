# AETHER — AIアシスタント

Flask製の日本語AIアシスタントです。ネオンブルーのホログラム風UIと、脈動するAIコアを備えています。Groq APIのモデル一覧から利用可能なチャット用テキストモデルを取得し、OpenAI互換チャット補完エンドポイントで会話します。ユーザーを「伊吹様」とお呼びし、Whisperなどの音声モデルは選択対象から除外します。

## 必要なもの

- Python 3.10+
- Groq APIキー（[Groq Console](https://console.groq.com/keys)で発行）

## 起動方法

1. 仮想環境を作成して有効化します。

   ```bash
   python -m venv .venv
   source .venv/bin/activate
   ```

   Windows PowerShellの場合:

   ```powershell
   .venv\Scripts\Activate.ps1
   ```

2. 依存パッケージをインストールします。

   ```bash
   pip install -r requirements.txt
   ```

3. `.env.example`を`.env`にコピーし、Groq APIキーを設定します。`.env`はCodespacesなどにあらかじめ設定された同名の環境変数より優先して読み込まれます。

   ```dotenv
   GROQ_API_KEY=your_groq_api_key_here
   ```

   APIキーはソースコードやブラウザー側のファイルに記載しないでください。

4. 開発環境ではアプリを起動します。

   ```bash
   python app.py
   ```

5. ブラウザーで <http://127.0.0.1:5000> を開きます。

Groq APIがHTTPエラーを返した場合は、ステータスコードと応答本文の一部をアプリ画面とFlaskのターミナルログに表示します。APIキーそのものはエラー表示・ログに含めません。

## Renderへのデプロイ

- Build Command: `pip install -r requirements.txt`
- Start Command: `gunicorn app:app --bind 0.0.0.0:$PORT`
- RenderのEnvironment Variablesに`GROQ_API_KEY`を登録してください。Flaskアプリも`PORT`環境変数を使用して起動します。

## 会話履歴と長期記憶

- 直近最大20往復分の会話ログはブラウザーの`localStorage`に保存され、同じブラウザー・プロファイルから再訪した際に復元されます。「RESET」は会話履歴だけを消去します。
- 長期記憶もブラウザーの`localStorage`に保存し、チャットごとにバックエンドへ渡してAIの前提知識に加えます。MEMORY BANKから確認・個別削除・全削除ができます。Renderの再起動や再デプロイでは消えません。
- `localStorage`はブラウザー・端末ごとの保存領域です。ブラウザーデータを消去した場合や別端末・別プロファイルでは復元されず、同じブラウザー内での同期にも対応しません。パスワードやAPIキーなどの秘密情報は記憶対象外です。

## Web検索

- ニュースを調べる場合とBRIEFINGでは、Googleニュース日本語RSSから最新記事を最大5件取得してAIに渡します。RSS通信・XML解析の失敗原因はFlaskのターミナルログにも記録します。
- それ以外のWeb調査ではAPIキー不要の`ddgs`でDuckDuckGoを検索します。検索対象ではない一般知識や雑談では検索しません。
- 検索結果を使った回答には、チャット内に検索完了ステータスと参照元リンクを表示します。検索に失敗した場合は状態を表示し、検索結果を捏造しないようAIに伝えます。

## 釧路市の天気とクイックランチャー

- Open-Meteoから北海道釧路市（緯度42.9849、経度144.3814）の現在の天気、気温、風速、当日の最高・最低気温と7日間の最高・最低気温予報を取得し、HUDに表示します。ブラウザーは5分ごとに更新し、サーバーも同じ時間だけ結果をキャッシュします。
- 取得した気象データはチャットのシステムプロンプトにも含まれます。場所の指定がない天気や服装の質問には釧路の情報を使い、釧路以外はDuckDuckGo検索を行います。
- QUICK PROTOCOLSにはBRIEFING（釧路の天気と日本の主要ニュース）、DATA SCAN、CODING（GitHub）、GAMING、WATCHINGを配置しています。DATA SCANはボタンを押したときだけクリップボードのテキストを読み取り、AIに日本語訳と3行以内の要約を依頼します。BRIEFINGは報告を行い、残りの外部プロトコルは新しいタブで対象サイトを開きます。ブラウザーがタブをブロックした場合は、チャットにリンクを表示します。

## 音声読み上げ

- 音声モードでAIが返答すると、`edge-tts`の日本語男性音声`ja-JP-KeitaNeural`を使ってMP3を生成し、ブラウザーで再生します。読み上げ用にMarkdown記法、URL、HUDステータスを整形し、再生中はAIコアが連動します。
- TTSの通信に失敗した場合だけブラウザーの`speechSynthesis`を予備として使います。

## ウェイクワード音声対話

- 会話欄の「VOICE STANDBY」をONにすると、日本語のブラウザー音声認識が待機し、「ジャービス」「じゃーびす」「Jarvis」を検知します。ブラウザーのマイク利用許可が必要です。
- 呼びかけ後は電子音とともに「はい。」と応答し、その再生が終わってから用件を認識してAIへ送信します。「ジャービス、今日の天気は？」のように続けて話した場合は、認識できた用件を「はい。」を挟まず送信します。
- AIの音声回答が終わると再びウェイクワードを待ちます。待機はスイッチをOFFにするかページを離れるまで継続します。音声認識の対応状況やバックグラウンド動作はブラウザーに依存します。

## HUD効果音

- ボタンのホバー・操作、送信・ウェイクワード、起動シーケンス、モード転換、AIの処理中・応答完了、外部ランチャー起動に連動するFM変調・フィルター処理を組み合わせた効果音をWeb Audio APIで生成します。音声ファイルは使用しません。
- 画面上部のSFXコントロールから効果音をミュートでき、音量は初期値30%から調整できます。
- 起動時は約2.5秒のシステム診断アニメーションを表示します。ブラウザーの自動再生制限により、起動音はシーケンス中に「ARM AUDIO LINK」を押すと再生されます。「SKIP SEQUENCE」または画面クリックで演出を終了できます。
- AUDIO SPECTRUMのAMBIENT COREスイッチは、Web Audio APIで低音の持続音と控えめな通信パルスを生成します。停止時は音量をフェードアウトします。

## 光学センサー

- OPTICAL SENSORをONにすると、ブラウザーのカメラ許可を得たうえで映像をHUD内にローカル表示します。映像はチャットやサーバーへ送信されません。OFFまたは画面を離れるとカメラのメディアトラックを停止します。
- カメラ利用にはブラウザーの許可と、HTTPSまたはlocalhostなどのセキュアコンテキストが必要です。カメラが未接続・未許可の場合はHUDに状態を表示します。画面上の距離・負荷値は演出用のシミュレーション表示です。

## ホログラム、緊急プロトコル、暗号化

- HOLO-3Dからアークリアクター／ヘルメットのワイヤーフレームを投影し、ポインターまたはタッチ操作で回転、EXPLODEで分解・再結合できます。GLOBAL RADARはCanvas上の地球儀、釧路基地、ISSの現在位置と取得済み軌道履歴を表示します。
- チャットまたは音声で「ハウスパーティープロトコル」「ハウス・パーティー・プロトコル」「全機起動」と入力すると、3秒の警告演出後にMARK-IIIへ切り替わり、所定の応答を表示・読み上げます。音声読み上げや効果音がミュートされている場合は設定を尊重します。
- STARK CIPHERはブラウザーのWeb Crypto APIを使い、PBKDF2（SHA-256）とAES-256-GCMで暗号化します。暗号文は`STARK1`形式で表示され、復号には暗号化時と同じパスフレーズが必要です。処理はブラウザー内で行い、暗号文やパスフレーズをサーバーへ送信・保存しません。パスフレーズを忘れると復号できません。

## HUDテーマモード

- 画面上部の「HUD MODE」スイッチでネオンシアン基調のSTANDARDと、深紅・ゴールド基調のMARK-IIIを切り替えられます。MARK-IIIでは結論優先の短い箇条書き回答になり、25分ミッションタイマーが表示されます。タイマーはSTART/PAUSEとRESETで操作でき、STANDARDへ戻すと一時停止します。通信波形、システム診断、釧路の7日間予報も表示します。切替時は走査線と照準アニメーション、Web Audio APIの効果音が連動します。
- 「マークスリー」「マーク3」「マーク３」「マークⅢ」「Mark 3」「Mark III」「アイアンマンモード」「戦闘モード」の入力でMARK-IIIに、「通常モード」「スタンダード」「解除」の入力でSTANDARDに切り替わります。モードはAIの応答口調にも反映されます。

## ISS追跡、AIR GESTURE、CLEAN SLATE

- GLOBAL RADARはAPIキー不要のWhere the ISS at? APIから国際宇宙ステーションの緯度・経度、高度、速度を5秒ごとに取得します。地球儀上のマーカーと軌道履歴、釧路からの直線距離を表示し、ISSの現在地に関する質問では取得した最新テレメトリーを質問データに添えて回答させます。位置情報が取得できない場合は、その旨をAIに伝えて推測を避けます。
- AIR GESTUREはMediaPipe HandsとCamera UtilsをCDNから読み込み、許可されたカメラ映像をブラウザー内で解析します。手の21点を使ったHOLO-3Dの回転・ピンチズーム・開いた手でのEXPLODEに対応します。「ジェスチャー起動」または「ハンドトラッキング」で開始し、スイッチをOFFにするとカメラを停止します。OPTICAL SENSORとは同時にカメラを使用しません。
- 「クリーンスレート」「クリーンスレートプロトコル」「履歴全消去」で3秒のCLEAN SLATE演出を開始し、完了時に会話履歴とそのブラウザー保存分を消去します。長期記憶は消去しません。Webカメラの許可にはHTTPSまたはlocalhostなどのセキュアコンテキストが必要です。いずれの追加機能もPythonパッケージは使用しません。

## シミュレーション、ホログラムノート、監視

- SIMULATEボタンまたは「〇〇のシミュレーションをして」「〇〇の攻略確率を計算して」という依頼で、目標・AIの成功確率推定・3段階の攻略案・リスクをまとめます。成功確率はモデルの概算であり、実際の成功を保証しません。MARK-IIIでは作戦ブリーフィング形式の指示もチャット本文に付加します。
- + HOLO-NOTEまたはAI回答の「HUDに展開」から、編集・ドラッグ可能なノートを複数作成できます。内容と位置はブラウザーの`localStorage`に保存されますが、暗号化・端末間同期はありません。
- SENTRY MODEはページ上のマウス・キーボード等の入力有無だけをブラウザー内で監視し、15分間入力がなければ継続／スタンバイを確認します。カメラや生体情報は取得しません。
- MARK-III限定の照準・飛行テレメトリー・氷結警告、および全モード共通の電力配分・情報ティッカー・システムログを表示します。電力、飛行値、生体認証バッジは演出用シミュレーションです。LOCKもブラウザー内の画面オーバーレイであり、認証やデータ保護を行うセキュリティ境界ではありません。
